      בלי תלויות חדשות). שליטה ב-הגדרות → Cloud sync, או ב-CLI.
      ראה [`docs/SYNC.md`](../docs/SYNC.md).

- [x] **סנכרון ענן** (2.4.0) — התחברות אנונימית + `users/{uid}/doses/{doseUid}`,

- [x] **ווידג'ט למסך הבית** (2.3.0) — רמה נוכחית של החומר הפעיל בצבעו +
